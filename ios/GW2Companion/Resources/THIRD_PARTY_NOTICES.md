# Third-party data

`tyrian-gathering-v1.json` is a converted snapshot of the
[Tyrian Gathering Marker Project](https://github.com/kriana/Tyrian-Gathering-Marker-Project)
at revision `b0baca72ee7519432cf54a94d3435878d0e74344`.

The source project dedicates the data to the public domain under
[CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/).
The converted data is provided as-is; locations are possible gathering spawns
and do not indicate that a resource is currently present in a map instance.
